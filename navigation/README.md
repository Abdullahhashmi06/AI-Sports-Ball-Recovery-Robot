# navigation

Autonomous navigation subsystem: deciding where the robot should go and how to get there safely.

## Subdirectories

- `localization/` — Estimating robot position and orientation (wheel encoders, IMU)
- `planning/` — Path planning: target recovery areas, search patterns, return-to-base routes
- `obstacle_avoidance/` — Obstacle detection responses and dynamic rerouting
